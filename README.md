# HR — Учёт сотрудников

Веб-приложение для кадрового учёта сотрудников организации.

## Стек
- **Бэкенд:** Node.js, Express, better-sqlite3
- **Фронтенд:** HTML, CSS, JavaScript
- **База данных:** SQLite

## Запуск

1. Установить зависимости:

Пишем в терминале
npm install

2. Заполнить тестовыми данными (опционально):

Пишем в терминале
node api/seed.js

3. Запустить сервер:

Пишем в терминале
node api/server.js


4. Открыть в браузере: http://localhost:3000

## Функциональность
- Просмотр всех сотрудников
- Фильтрация по отделу и должности
- Поиск по ФИО
- Добавление нового сотрудника
- Редактирование информации
- Увольнение (сотрудник остаётся в таблице с меткой «Уволен», редактирование блокируется)
- Маски ввода для паспорта и телефона
